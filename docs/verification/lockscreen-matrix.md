# 잠금 화면 검증 기록

## 판정

아직 실기기 자동 갱신·잠금 노출·장기 유지 검증을 수행하지 않았습니다.

## 시험 절차

1. 시험키 사용을 켜고, 원형과 시간 위 한 줄 위젯을 각각 추가합니다.
2. 별도 참조 TOTP와 비교하며 30초 경계를 여러 번 관찰합니다. 앱을 열거나 위젯을 누르지 않습니다.
3. Face ID 전 실제 잠금과 인증 후 잠금 화면을 나누어 기록합니다.
4. 화면 꺼짐·상시 표시·저전력·비행기 모드·앱 강제 종료를 각각 시험합니다.
5. 기본 1시간 타임라인의 보충과 밤새 방치 후 첫 표시를 확인합니다.
6. 실제 키 시험은 별도 진행합니다. 키체인 공유·설정 변경·계정 삭제·재부팅 후 첫 해제 전 접근을 확인합니다.

기록 필드: iOS 빌드, 기기, 모드, 관찰 시각, 전환 지연, 마지막 앱 실행 시각, 합격/실패/미확인. 실제 키·코드는 기록하지 않습니다.

앱 내부 미리보기, 단위 시험, 시뮬레이터 실행, 실기기 위젯 자동 전환은 서로 다른 검증 수준입니다.
