# 독립 검토 판단

첫 독립 검토는 보수적으로 실패 판정을 반환했습니다. 부모가 소스와 대조한 결과:

- 저장 실패 후 메모리 변경이라는 지적은 코드와 다릅니다. VaultStore.change는 값 타입 복사본 next만 수정하고 KeychainVault.save가 성공 반환한 뒤 vault에 대입합니다. SecItemAdd 폴백도 errSecItemNotFound일 때만 수행하며 접근 거부에는 호출하지 않습니다.
- 위젯 갱신과 보호 정책의 즉시 동기화 미보장은 실제 한계입니다. 기존 타임라인 화면이 남을 수 있음을 동의 화면·삭제 확인·개인정보 문서에 고지합니다. 보안 정책이 즉시 적용된다고 주장하지 않습니다.
- GitHub Secrets의 서명키는 배포 인증에만 사용합니다. 공개 소스에 키는 없으며 일회성 호스티드 러너의 파일 권한은 0600, 워크플로 종료 시 삭제 단계를 추가했습니다. 런너와 저장소 관리자는 신뢰 경계에 포함됩니다. OIDC를 Apple 서명 API가 직접 지원한다고 가정하지 않습니다.
- 실기기 자동 갱신 미검증은 배포할 시험 앱의 알려진 한계이며 단위 시험·시뮬레이터 성공으로 대체하지 않습니다. 시험키로 실기기 검증할 수 있는 테스트 배포와 제품 검증 완료를 구분합니다.

이 문서는 검토 이견의 근거이며 새 시험 결과를 만들거나 실기기 성공을 선언하지 않습니다.
