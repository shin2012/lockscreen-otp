# 개인정보와 인증키

- 앱의 시험키는 RFC 6238에 공개된 `12345678901234567890` 시험 벡터입니다. 운영 비밀키가 아닙니다.
- 실제 키는 사용자가 앱에서 직접 입력합니다. 서버·소스·CI·분석 도구로 전송하지 않습니다.
- 계정·비밀키·설정은 앱과 위젯만 공유하는 기기 내부 Keychain 항목 하나에 저장합니다. iCloud 동기화·내보내기·복구 기능은 없습니다.
- 기본 보호는 WhenUnlockedThisDeviceOnly입니다. 실제 계정 위젯 접근에 명시적으로 동의하면 항목 전체가 AfterFirstUnlockThisDeviceOnly로 바뀝니다. 따라서 저장된 모든 계정 키가 재부팅 후 첫 잠금 해제부터 백그라운드에서 접근 가능합니다.
- 잠긴 상태 번호 노출은 별도 동의가 필요합니다. 기본값은 privacySensitive로 숨깁니다. 기기 설정과 실제 잠금 상태에서의 동작은 실기기로 확인해야 합니다.
- 위젯 타임라인에는 사전 계산 코드가 들어갑니다. 키가 아닌 코드도 민감 정보입니다. 설정 변경·계정 삭제 직후에도 시스템 캐시에 기존 화면이 남을 수 있습니다. 즉시 회수를 보장하지 않습니다.
- 앱 비활성 시 화면 가림 처리를 합니다. OS 스크린샷 방지나 악성 기기로부터의 보호를 보장하지 않습니다.
- 기존 서비스의 인증 수단을 이 앱 검증 전까지 삭제하거나 교체하지 마세요.
- 진단 화면·CI 캡처는 공개 시험키만 사용합니다. 실제 계정 화면은 버그 제보에 첨부하지 마세요.
- 앱은 실험 단계입니다. 코드 정확성 단위 시험과 iOS 위젯 갱신 신뢰성은 별개입니다.
